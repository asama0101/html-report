# create の手順8・10: 案の選択と後始末

読むとき: create の手順8 に入る直前（手順10 の前にも、この内容が会話に見えなければ読み直す）。何のための手順書か: 検査に通った全案を利用者のブラウザで開いて選んでもらい（手順8）、選ばれなかった案を削除して、選ばれた案の名前から案名を外す（手順10）。「守ること」と用語は、SKILL.md のとおり。

### 手順8: 選択
手順7 で検査の不正が残った案を除いた、案ごとのファイルを Bash で開き、AskUserQuestion で、案の名前から選んでもらう。不正が残った案は、選択肢に出さず、`start` で開かない（手順7 で削除できなかったときは、残っているパスを手順11 で伝える）。

#### 案を開く
- 保存先のフォルダ（手順6 で許可されたパス）へ `cd "<保存先のフォルダ>"` したうえで、ファイル名だけを `start "" "<ファイル名>"` に渡す。フルパスは渡さない（フォルダ名に `&` があると開けない。ファイル名は手順6 で許可した文字だけなので、そのまま渡せる）。
- `cmd /c` と PowerShell は使わない（Git Bash では `cmd /c` の `/c` がパスに変換され、実行されない）。
- 開けないときは、ほかの方法を試さず、パスを伝える。

#### 選んでもらう
- デザインの選択は、毎回行う（依頼文にデザインの指定があるときも省かない）。
- 選択肢には、案の名前と、手順4 で書いた 1〜2 行の説明を出す。崩れが残った案は、「崩れが残っている」と添える。
- 質問文に「選ばなかった案のファイルは、このあと削除する（元に戻せない）。残したい案は、答える前に別の場所へコピーする」と書く。
- 不正を除いて案が 1 つだけ残ったときは、AskUserQuestion で「この案で進める／作り直す」を聞く。「作り直す」は、下の「その他」と同じ扱いにする。
- AskUserQuestion が使えない実行では、案を文章で出して止まる。

#### 「その他」の自由記述（作り直し）
- 「その他」の自由記述で、混ぜたい・どれも合わないと言われたときは、その内容を受けて、手順4〜7 をやり直して全案を作り直し、もう一度選んでもらう。回数の上限はない。
- 作り直す前の案のファイルは、作り直した案を保存する前に、手順6 で自分が保存した案のパスを、1 つずつ指定して削除する。ワイルドカードは使わない。
- これは初版の案の選び直しであり、完成後の修正の支援ではない。

#### 選ばずに終わるとき・止まるとき
選ばずに終わる（選択の質問に答えが得られないまま、実行が終わる）ときと、止まるときは、検査に通った案のファイルをすべて残し、案ごとの保存先の絶対パスと、削除するコマンドを伝える。

### 手順10: 後始末
手順6 で許可されたパスを使い、次を行う。利用者の素材と、もとからあるファイルは消さない。
- この作業で作った、選ばれなかった案のファイルを、1 つずつパスを指定して削除する（手順9 で選ばれた案を削除したときも行う）。
- 選ばれた案を、案名のない `YYYY-MM-DD-題名.html` にする（同名のファイルがあるときの扱いは、手順6 の保存の項目に従う）。
