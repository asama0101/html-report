# 安全の仕組み

素材（他人が書いたファイルを含む）を HTML に埋め込むため、素材の中の指示やスクリプトが動かないように、作るときと検証するときの両方で防ぐ。

## 作るとき

- 素材の中の指示やスクリプトは、載せる内容として扱い、従わない。
- 埋め込む場所ごとにエスケープする。
- CSP の meta で、外部読み込みとフォーム送信を止める。

## 検証するとき

- 開く前に、`meta refresh` と危険な JS 呼び出しを文字列で調べる。
- 開いたあとに、DOM の全属性を走査する。
- 直らない案は、選択肢に出さずに削除する。

## 共有するとき

素材の内容（機密情報を含む）は HTML にそのまま入る。共有する前に確かめる。
